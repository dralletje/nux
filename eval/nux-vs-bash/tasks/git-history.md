This folder is a git repository. Answer these questions about its history, and write the
answers to `answer.json` in this folder, as one JSON object with these keys:

- `parse_config_added_in`: the commit hash (full, or at least 7 characters) of the commit
  that first added the function `parseConfig`.
- `legacy_deleted_in`: the commit hash of the commit that deleted `src/legacy.js`.
- `most_changed_file`: the path of the file that the most commits changed (as git prints
  it, e.g. `src/server.js`).
- `lines_added_by_carol`: the total number of lines added, over all commits, by the
  author Carol Example (a number).

Do not change the repository.

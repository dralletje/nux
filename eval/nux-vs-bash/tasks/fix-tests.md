This folder is a small Node.js project; its tests run with `node --test`. Some of them fail.

1. Find out which tests fail.
2. Fix the bugs in `src/` so that every test passes. Do not change the tests.
3. Write `answer.json` in this folder: `{"failed_before": [...]}`, the names of the tests
   that failed before your fix, exactly as the test runner names them.
